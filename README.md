Codex Local — независимое Windows-приложение для работы с установленным Codex через App Server. Собирайте чаты по проектам, следите за несколькими задачами и возвращайтесь к важным ответам без потери контекста.

Этот репозиторий содержит **готовые установщики и документацию**. Исходный код приложения хранится отдельно и не публикуется здесь. Приложение не является официальным продуктом OpenAI.

## Что умеет

| Возможность | Для чего |
| --- | --- |
| Несколько чатов и «Фокус» | Один большой чат и карточки работающих задач и непрочитанных ответов |
| Проекты, поиск и закладки | Быстро находить нужный чат и сохранять важные сообщения |
| Ход работы | Видеть события текущей задачи и управлять показом завершённой работы |
| Файлы и изменения | Читать код с подсветкой, переходить к изменениям, открывать HTML-превью |
| Темы | Светлые, тёмные и собственные цвета с предпросмотром |
| Черновики и очередь | Сохранять незавершённый ввод и готовить следующие сообщения |
| Уведомления и PWA | Получать вопросы и результаты, открывать панель с других устройств |
| Проверенные обновления | Устанавливать новые выпуски с проверкой подписи и сохранением работающих задач |

## Установка

1. Установите **Codex для Windows** и войдите в свой аккаунт. Нужен доступ к Codex; панель не предоставляет подписку и не увеличивает лимиты.
2. Скачайте файл **`Codex-Local-Setup-…exe`** из [последнего выпуска](https://github.com/DenisG1302/codex-local/releases/latest).
3. Запустите установщик и откройте Codex Local. При первом запуске создайте локальный аккаунт панели.

Нужны Windows x64 и Microsoft Edge WebView2 Runtime. Node.js включён в установщик. Интерфейс приложения сейчас на русском языке; документация и описания новых выпусков доступны на русском и английском.

Для скачивания не нужны GitHub-аккаунт, доступ к закрытому репозиторию или инструменты разработки. Архивы **Source code**, которые GitHub добавляет автоматически, содержат только документацию этого репозитория. Для установки выбирайте EXE.

## Обновления

Откройте **Настройки → Обновления**. Здесь видна текущая версия; кнопка **«Проверить и обновить»** сама скачивает, проверяет и устанавливает новую версию. При запуске приложение также сообщает о доступном обновлении. Рабочие задачи выполняются в отдельном процессе и продолжаются во время обновления панели.

Обновление принимается только с действительной подписью выпуска и совпадающей контрольной суммой EXE. Это собственная проверка обновлений приложения, а не сертификат издателя Windows. Windows может показывать предупреждение об неизвестном издателе. Первую установку скачивайте только из этого репозитория.

## Данные и доступ

Установщик не содержит чужих аккаунтов, переписки, файлов проектов или настроек подключения. Данные панели создаются на вашем ПК в `%LOCALAPPDATA%\CodexLocal`; авторизацией Codex управляет сам Codex. Панель обращается к GitHub за обновлениями и к Codex Resets за публичным расписанием сбросов. Запросы к моделям обрабатываются сервисами, к которым подключён ваш Codex.

Веб-доступ защищён локальным аккаунтом панели. Для телефона откройте **Настройки → Подключение**; для PWA с push-уведомлениями нужен настроенный HTTPS-доступ. Не публикуйте пароль панели или файлы авторизации.
